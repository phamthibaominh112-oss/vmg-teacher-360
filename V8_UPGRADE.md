# V8 · Compact Academic Balance

This UI-only revision keeps V7's academic identity while reducing visual overload.

- Footer remains anchored to the bottom of short pages, but is not sticky.
- Footer height is reduced substantially; partner marks remain visible in a compact trust strip.
- 23-year proof and CEFR / skills / teacher-development proof points stay, in a denser row.
- Resource Library starts closer to its page introduction and uses slightly tighter visual cards.
- Home academic badges are reduced slightly to avoid repeating the footer's trust content.
- No database or Supabase migration changes.
